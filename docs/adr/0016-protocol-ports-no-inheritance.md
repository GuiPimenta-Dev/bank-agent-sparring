# Ports are Protocols, classes compose instead of inherit, and wiring is explicit

Ports are `typing.Protocol`s, so adapters satisfy them structurally without inheriting; `pyright --strict` checks compatibility where an adapter is injected. Class inheritance is banned in our code except where Python or a library requires it (defining a `Protocol`, subclassing `Exception`, subclassing Pydantic's `BaseModel`); reuse happens by receiving a collaborator through the constructor. Dependencies are injected by constructor only, with no DI framework: each entrypoint (MCP server, Exploration CLI, Regression Check CLI) has one composition root that wires the object graph explicitly. Tests use the real test adapters (in-memory repositories, a fixed clock) instead of mocks. A port exists only at a real boundary — repositories, `Clock`, the Simulated User's LLM client, Langfuse — never for a domain service with a single implementation.
