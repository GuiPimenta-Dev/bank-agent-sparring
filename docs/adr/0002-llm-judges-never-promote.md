# LLM judges may flag or block, never promote

A Failure enters the Golden Set only on deterministic evidence: a final-state mismatch against the Oracle's Expected Outcome, or an Invariant violation over the tool-call trajectory. LLM judges still run (tone, clarity, possible Policy drift) and their results are recorded as scores, but they can only flag a conversation for review or block a promotion — never cause one. This asymmetry keeps the Golden Set free of judge hallucinations while still using judges for signal that code cannot capture.
